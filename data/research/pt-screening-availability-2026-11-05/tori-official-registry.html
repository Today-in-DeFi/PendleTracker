Contract Addresses

Official, verified Tori Finance contract addresses for trUSD, strUSD and minting on Ethereum and other chains, with cross-chain transfers via Chainlink CCIP.

Always verify contract addresses before interacting. Only use the official addresses listed on this page.

​
Multi-chain architecture

trUSD and strUSD support native cross-chain transfers via Chainlink CCIP using the Cross-Chain Token (CCT) standard. Ethereum Mainnet is the hub and holds the canonical token behind a Lock & Release CCIP token pool; each additional chain uses a Burn & Mint token pool. Monad, Pharos, Arbitrum and Solana are live; their addresses are listed below. Bridging explains how to move tokens between them.

Chainlink CCIP token pools

The canonical trUSD and strUSD above are bridged through Lock & Release token pools. Tokens sent to another chain are locked and released on the way back. The locked tokens sit in a lockbox for each token, which the pool releases from; the lockboxes’ balances are the backing of every trUSD and strUSD minted on Monad, Pharos, Arbitrum and Solana.

Solana

CCIP chain selector 124615329519749607. trUSD and strUSD on Solana are SPL tokens (the classic SPL Token program, 9 decimals) minted and burned by Chainlink’s Burn & Mint token pool program: every unit in circulation here is locked in the Ethereum lockboxes above. Solana has lanes to Ethereum, Monad and Arbitrum, both ways, each with a rate limit of 1,500,000 tokens refilled over six hours. There is no lane between Solana and Pharos. Tori deploys no Solana program of its own.

Verification

Every Ethereum contract above is verified on Etherscan, with source code matching the deployed bytecode. The same source is published at github.com/Tori-Finance/tori-contracts, where forge build reproduces the deployed code. The protocol has been audited by Sherlock and Nethermind; the reports, each with its scope, are on the audits page. The CCIP token pools are Chainlink’s own audited contracts, deployed unmodified through the CCIP token pool factories.
